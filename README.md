Lunex.lol UI Library

""License: MIT" (https://img.shields.io/badge/License-MIT-yellow.svg)" (https://opensource.org/licenses/MIT)

A sleek, minimalist Linoria-style UI library for Roblox. Built for scripters who want a clean, customizable interface without unnecessary bloat.

---

Features

- Modern Linoria-inspired design – Clean, dark, and minimal
- Mobile-friendly – Responsive layout designed to work across different screen sizes
- 12+ UI controls – Checkbox, Slider, Combo (dropdown), Keybind, ColorPicker, and more
- Full theming system – Built-in presets with support for custom colors
- Config manager – Save and load configurations with ease
- Theme manager – Create, save, load, and delete custom themes
- UI customization – Customize colors, watermark, and other interface settings
- Auto-load support – Automatically load your last used configuration
- Resizable window – Adjustable window size with optional resize handles
